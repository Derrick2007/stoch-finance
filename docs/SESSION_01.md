# 第一次任务：理解并核查 GBM Monte Carlo

预计两次各 1–2 小时的学习/实现时段，按理解程度调整。核心代码尚未代写，后续小步实现。

## 先回答

1. 为什么 Brownian increment 是 sqrt(dt) Z，而不是 dt Z？它的均值和方差是什么？
2. 为什么 GBM 的 log solution 出现 -sigma²/2？
3. 定价中为什么用 r 作 drift，并在 payoff 外乘 exp(-rT)？
4. 一个模型的路径模拟，与某个期权的定价估计，分别返回什么？

## 实现顺序

1. 定义参数与输入校验，sigma 和 T 先限定为正数。
2. 实现正态 CDF 与 Black–Scholes call 参考公式，可用标准库 math.erf。
3. 用 NumPy Generator 实现精确 S_T 抽样，不必保存所有中间路径。
4. 计算折现 payoff 的平均值、样本标准差、标准误和近似 95% 区间。
5. 固定 seed 跑一个示例，再用独立 seeds 评估 N=1000、10000、100000 的重复误差。

## 验证

- 价格参考约 10.4506（S0=K=100,r=0.05,sigma=0.2,T=1）。
- 精确 S_T 应保持正值，样本均值应接近 S0 exp(rT)，但统计差异需按标准误理解。
- 在多个独立重复中，RMSE 应呈近似 N^(-1/2) 的趋势；单次误差不保证随 N 单调下降。
- 单次置信区间不覆盖参考价格，不应直接写成必然失败的测试。
