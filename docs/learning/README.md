# 我的学习日志

这是长期学习记录，不要求每周做完固定数量的内容。每次只解决一个能用自己的话讲清楚的小问题。

## 使用方式

1. 开始学习前写下今天的问题。
2. 学习和实现后，用自己的话填写日志；不理解的地方直接保留。
3. 隔几天先不看笔记，回答复习问题，再核对和修正。
4. 一次学习的代码、验证结果和日志一起提交到 Git，保存变化过程。

参考节奏：每周约 8 小时，数学学习 3 小时、实现与验证 3 小时、总结与复习 2 小时；根据课程负担调整。
