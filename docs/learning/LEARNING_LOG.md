- 一轮聚焦一个概念：解释 → 小例子 → 用户尝试回答 → 反馈 → 必要时实现少量代码。
- 根据回答调整速度；尚未回答或仅听过的内容不记为已掌握。
- 每次记录讲解内容、用户反馈、代码与验证、疑问、下一步。
- 用户自己的总结写在日期日志里；工程完成情况写在 docs/PROGRESS.md。
- 每个小阶段整理一次复习，并把有意义的日志与代码变化同步到私有 GitHub。
