## 2026-10-05 — 期望与 Monte Carlo 的直觉

- 根据用户反馈继续，避免重复简单行权问题。
- 本轮讲解：假设 S_T 为 80、100、130，概率分别为 0.25、0.50、0.25。payoff 为 0、0、30，期望收益为 7.5；期望股价为 102.5。先平均股价再算 payoff 会得到 2.5，与平均 payoff 不同。
